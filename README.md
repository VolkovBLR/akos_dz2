# Индивидуальное задание № 2 — вариант 20 «Автогонки»

Многопоточная консольная имитация гонки по правилам В. Пудова
(«Наука и жизнь», № 12, 1983) для ОС Linux.

## Сборка

```bash
make
```

Появляются два бинарника:

- `race` — синхронизация **мьютексами и семафорами**
- `race_cond` — вместо семафоров **условные переменные**

## Запуск

```bash
./race
./race -c configs/default.conf
./race -n 3 -p 2 -k 2 -s 1 -d 40 -l race.log
./race -i
./race_cond -c configs/short.conf
```

Завершение: по финишу/сходу всех машин, по пределу раундов или по `Ctrl+C` (SIGINT/SIGTERM).

Подробности, сценарий потоков и результаты — в `ОТЧЕТ.md`.
Тесты: `make test`.
